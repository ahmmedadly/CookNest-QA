# CookNest-QA

This repository contains manual testing artifacts for an Android Food Planner application.

## Features Tested
- Meal of the day
- Search by country, ingredient, and category
- Favorites (Room database)
- Weekly meal planning
- Offline access
- Authentication (Firebase)
- Guest mode

## Known Issues

- Mobile calendar integration not working

## Deliverables
- Manual test cases
